PC·폰 동기화 설정

기록은 이 기기에서 비밀번호로 암호화된 뒤 본인 GitHub 비공개 저장소에만 올라갑니다. Claude 계정이나 다른 서버에는 저장되지 않습니다.
처음 설정하는 방법 (PC에서 한 번, 약 10분)
  1. github.com 가입/로그인 → 오른쪽 위 + → New repository → 이름 recovery41-data, Private 선택 → Create.
  2. 프로필 사진 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Expiration: Custom → 2027년 1월 이후 날짜 · Repository access: Only select repositories → recovery41-data 하나만.
  4. Permissions → Contents: Read and write → Generate → 나온 토큰(github_pat_…)을 위 칸에 붙여넣기.
  5. 비밀번호를 정하고 연결하고 동기화. 그다음 폰 연결 링크·QR로 폰에서 열고 같은 비밀번호만 입력하면 끝.
